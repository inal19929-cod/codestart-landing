Frontend-разработка
6 месяцев · с нуля до Junior

О направлении

Frontend — это всё, что пользователь видит и с чем взаимодействует в браузере. Ты будешь создавать интерфейсы сайтов и веб-приложений: от лендингов до сложных SPA на React. Одно из самых востребованных направлений: junior-разработчики нужны почти каждой компании.

Чему научишься

  • Вёрстка HTML5 и CSS3, Flexbox, Grid, адаптивность
  • JavaScript с нуля до продвинутого уровня, ES6+
  • React, хуки, работа с состоянием, React Router
  • Работа с API, fetch, асинхронность, Git и GitHub
  • Сборка проектов через Vite, деплой на Vercel

Backend-разработка
8 месяцев · с нуля до Junior

О направлении

Backend — это «мозг» любого приложения: логика, базы данных, API, безопасность, интеграции. Если тебе интересно, как устроены системы изнутри и как обрабатываются миллионы запросов — это твоё направление. Backend-разработчики — одни из самых высокооплачиваемых в IT.

Чему научишься

  • Python с нуля, ООП, работа со структурами данных
  • FastAPI / Django, создание REST API
  • SQL и PostgreSQL, проектирование баз данных
  • Асинхронность, Redis, очереди, Docker
  • Git, CI/CD, деплой приложений на сервер

QA-тестирование
5 месяцев · с нуля до Junior

О направлении

QA-инженер следит за качеством продукта: находит баги, проверяет функциональность, пишет автотесты. Это самый лёгкий вход в IT — не нужна глубокая математика, но нужно внимание к деталям. Отличный старт для тех, кто хочет быстро войти в профессию.

Чему научишься

  • Основы тестирования, виды и уровни тестов
  • Тест-дизайн, чек-листы, тест-кейсы, баг-репорты
  • Работа с Postman, DevTools, SQL для тестировщика
  • Автотесты на Python + Selenium и Pytest
  • Jira, TestRail, работа в Agile-командах

Data Science
9 месяцев · с нуля до Junior

О направлении

Data Science — работа с данными и машинным обучением. Ты будешь строить модели, которые предсказывают поведение пользователей, оптимизируют бизнес-процессы и решают задачи, недоступные классическому программированию. Престижное и высокооплачиваемое направление.

Чему научишься

  • Python, NumPy, Pandas, визуализация данных
  • Математика и статистика для DS: от основ до ML
  • Машинное обучение: Scikit-learn, регрессии, классификация
  • Нейросети, TensorFlow / PyTorch, основы NLP и CV
  • SQL, Airflow, основы MLOps и деплоя моделей
